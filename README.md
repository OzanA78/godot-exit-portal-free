# Sci-Fi Exit Portal — Free

A free, drop-in **sci-fi portal effect** with a textured **sci-fi room** for Godot 4.
Fully procedural, no external dependencies.

From the Android game **Time Echo**.

## What's inside

| File | Description |
|------|-------------|
| `portal_wobble.tscn` / `.gd` | Wobble-style energy portal — precessing coin-shaped rings. |
| `exit_room.tscn` / `.gd` | Sci-fi room with aspect-preserving wall + floor texture tiling. |
| `orbit_camera.gd` | Mouse-drag orbit camera with scroll zoom. |
| `showcase.tscn` / `.gd` | Ready-to-run preview scene (press **Esc** to quit). |
| `meshes/wobble.res` | Pre-baked portal mesh. |
| `portal_disk.gdshader` | Energy disk shader. |
| `textures/tex_02.png` | Sample wall + floor texture. |

## Quick start

1. Copy the `addons/exit_portal_free` folder into your project's `addons/` directory.
2. Open `showcase.tscn` and press **F6** to preview, or drag `portal_wobble.tscn`
   and `exit_room.tscn` into your own scene.

Enable **Glow** in your `WorldEnvironment` for the best look.
